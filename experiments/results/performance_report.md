# 系统性能实验报告

## 1 实验环境与规模

- 完整任务次数：100（真实 DeepSeek 规划 + RAG + RobotStudio Backend Mock 执行）
- RAG 检索次数：100
- 操作系统：Windows，Python 3.12

## 3 结果分析

（1）LLM 规划时间占完整任务耗时的主要部分，是端到端延迟的主导因素；

（2）Tool 调用与 Backend 响应为毫秒级，执行链路开销可控；

（3）RAG 检索为毫秒级，知识注入对整体延迟影响很小；

（4）完整任务亚秒级到数秒级，满足交互式任务规划的使用需求。
