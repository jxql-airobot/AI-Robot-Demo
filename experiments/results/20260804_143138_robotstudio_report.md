## 指标定义

- 成功率：计划匹配任务期望（工具/动作/目标）且所有步骤执行 ok
- 响应时间：Agent 处理总耗时（规划 + 执行）
- 规划时间：planner.plan 耗时（DeepSeek API / 离线规划器）
- 执行时间：工具链执行耗时（RobotStudio TCP 命令为主）
- RAG 召回率：期望记忆是否进入查询 top-3（来源：语义检索/关键词检索）
- 失败原因：自动分类记录（计划不匹配 / 步骤执行失败 / RAG 召回失败）
