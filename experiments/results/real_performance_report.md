# 真实 RobotStudio 性能测试报告

## 1 实验环境与规模

- 完整任务次数：100（真实 RobotStudio + IRC5 执行，真实 LLM 规划 + RAG）

## 2 性能指标

| 指标 | 平均 ± 标准差 |
| --- | --- |
| LLM 规划时间 | 3232.4 ± 5516.7 ms |
| RAG 检索时间 | 5.2 ± 7.4 ms |
| 执行时间 | 378.3 ± 411.6 ms |
| 完整任务耗时 | 3611.2 ± 5615.3 ms |

## 3 结果分析

真实 RobotStudio 执行链路下，LLM 规划仍为主要耗时；执行时间反映
TCP 通信与虚拟控制器运动执行时延。
