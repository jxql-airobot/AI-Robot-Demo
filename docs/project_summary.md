# 项目总结（软著 / 毕设材料）

## 项目名称

**基于大语言模型的机器人智能体任务规划系统**

## 1. 软件简介

本系统是一个融合大语言模型、智能体（Agent）架构、检索增强生成（RAG）与
机器人仿真技术的任务规划系统。用户通过自然语言向系统下达任务，系统经由
AI Agent 理解意图、生成可解释任务计划、调用记忆与机器人工具，并通过 ROS2
通信驱动 Gazebo 仿真机器人执行任务，最终将执行状态反馈给用户。

## 2. 功能描述

1. **自然语言任务理解**：基于 DeepSeek 大模型，将口语化指令解析为
   结构化 JSON 动作指令
2. **可解释任务规划**：输出任务分析、目标、执行步骤、当前状态四要素计划
3. **长期记忆管理**：SQLite 持久化记忆，支持环境/物体/用户知识三类
4. **语义记忆检索（RAG）**：向量嵌入 + 混合检索，召回语义相近记忆
5. **Agent 工具调用**：记忆、机器人、视觉、环境四类工具统一接口
6. **ROS2 机器人通信**：节点化大脑与控制器，话题发布-订阅
7. **Gazebo 仿真执行**：差速机器人物理导航 + 相机视觉感知
8. **图形化交互界面**：Streamlit 可视化对话、状态、记忆、视觉、机器人数据

## 3. 技术特点

- **LLM 结构化输出**：JSON 契约 + 低温采样，保证规划可执行
- **Agent 工具化架构**：BaseTool 统一接口，模块可扩展
- **轻量 RAG**：SQLite 向量表 + numpy 余弦相似度，零外部服务依赖
- **分层双栈**：Windows 单机验证栈 + WSL ROS2/Gazebo 仿真栈，核心复用
- **可观测性**：可解释 Plan 与逐步骤执行结果可视化

## 4. 应用场景

- 教学科研：AI 机器人课程设计、毕业设计、科研演示
- 智能仓储/柔性制造：自然语言驱动的搬运分拣任务规划
- 人机协作：非专业人员通过语言控制机器人
- Agent 技术研究：LLM 规划、工具调用、RAG 记忆的实验平台

## 5. 模块组成

| 模块 | 说明 |
| --- | --- |
| 交互层（gui/） | Streamlit 界面、ROS2 客户端、语言配置 |
| 智能体层（agent/） | Agent 主类、规划器、执行器、上下文、四工具 |
| 语义记忆层（agent/rag/） | 嵌入器、向量存储、混合检索 |
| 核心算法（llm/memory/robot.py） | DeepSeek 规划、SQLite 记忆、世界模型 |
| 机器人通信（ros2_ws/src/ai_robot） | 大脑/控制器/视觉节点、launch |
| 仿真模型（models/） | 差速机器人 URDF、彩色零件 SDF |
| 启动体系（scripts/） | 一键启动 4 窗口（V1/V2 + ROS2 + 终端 + GUI） |

## 6. 运行环境

- Windows：Python 3.12、Streamlit、OpenAI SDK
- WSL2 Ubuntu 22.04：ROS2 Humble、Gazebo 11、Python 3.10、
  OpenCV、sentence-transformers、torch（CPU）
