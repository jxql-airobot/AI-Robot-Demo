# 论文中文阅读备份系统

本目录用于存放毕业论文相关文献的中文阅读笔记，作为个人学习资料，不对外
发布，不替代原文。笔记只做理解和归纳，不生成正式引用，不修改论文内容。

## 笔记格式

每篇论文生成一个 Markdown 文件，命名规则：

    <第一作者拼音>-<年份>-<论文关键词>.md

示例：

    lewis-2020-retrieval-augmented-generation.md

每篇笔记包含七个部分：

1. 中文标题
2. 中文摘要
3. 研究背景
4. 方法总结
5. 实验总结
6. 关键概念解释
7. 我的项目关联分析

模板见 [_template.md](_template.md)。

## 使用说明

1. 将论文 PDF 放入 Zotero 文献库（或指定目录）；
2. 阅读 PDF 后按模板填写笔记；
3. 笔记坚持个人语言，避免照抄原文；
4. 重要结论用原文页码标注出处（如 p.3）；
5. 与本文系统相关的思考写入“我的项目关联分析”。
