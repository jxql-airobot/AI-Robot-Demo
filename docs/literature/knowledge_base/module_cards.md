# 项目模块知识卡

每张卡：相关论文 → 核心观点 → 项目对应实现 → 论文章节 → 答辩一句话。

---

## 模块 1：Agent（任务规划与执行管理）

- 相关论文：[15] ReAct、[16] Agent 综述、[18] HuggingGPT、扩展 ChatGPT
  for Robotics
- 核心观点：LLM 只是语言能力，Agent 补上"理解-规划-调用工具-反馈"闭环；
  ReAct 证明推理与行动交错能减少幻觉并提升决策成功率
- 项目对应：Agent 承担任务理解、拆解、工具调用、动作生成；规划器接口
  可插拔（LLM/规则）
- 论文章节：2.2、3.2、4.2
- 答辩一句话："我们的 Agent 参考了 ReAct 的推理-行动-反馈闭环，但用
  JSON 动作契约把动作限定在工业可执行范围内。"

---

## 模块 2：RAG（工业知识增强）

- 相关论文：[19] RAG、[4] LLM 综述
- 核心观点：参数化记忆难溯源、难更新；外接可检索知识库让生成有据可依；
  RAG 论文在三个开放域问答任务上达到当时最优
- 项目对应：SQLite 记忆 + bge-small-zh-v1.5 向量化 + 混合检索，
  规划前注入 top-k 知识
- 论文章节：2.3、3.3、5.3
- 答辩一句话："RAG 解决的是知识时效和溯源问题；我们的实验里语义检索
  召回率从 0% 提升到 100%，参数命中从 0~2 提升到 3~4。"

---

## 模块 3：RobotTool 与机器人技能

- 相关论文：[6] SayCan、扩展工厂机器人论文
- 核心观点：LLM 高层知识必须受机器人实际能力约束；SayCan 用
  p(useful)×p(feasible) 选技能，工厂机器人论文用 LLM+对话生成可执行任务
- 项目对应：RobotTool 统一工具接口，动作契约限定
  move_home/joint_move/linear_move/get_position/get_pose
- 论文章节：3.4、4.4
- 答辩一句话："SayCan 用价值函数做可行性约束，我们用动作白名单和安全
  校验，目标一致——不让 LLM 输出超出机器人能力的话。"

---

## 模块 4：后端解耦与底层通信

- 相关论文：[10] ROS2、[11] Gazebo、[12] RobotStudio
- 核心观点：ROS2 以节点/话题/中间件实现松耦合；Gazebo 提供仿真验证；
  RobotStudio 提供工业虚拟控制器
- 项目对应：RobotTool→Backend 插件化，Local/Gazebo/RobotStudio 三后端
  共用一套 Agent；ABB 走 TCP 127.0.0.1:30000 + RAPID SocketServer
- 论文章节：2.4、2.5、4.3、4.4
- 答辩一句话："我们借用 ROS2 的节点化和松耦合思想设计了 Robot Interface，
  执行后端可替换，Agent 不感知底层通信差异。"

---

## 模块 5：安全约束层

- 相关论文：[6] SayCan（能力约束）、[9] RT-2（无显式约束的反例）、
  扩展 Foundation Models（安全性挑战）
- 核心观点：LLM 输出不可控是工业落地的核心障碍；需要显式动作白名单、
  序列规范化和可达性校验
- 项目对应：动作契约校验 + 安全序列规范化（直线运动前置关节过渡、
  目标收敛到验证过的可达位姿）
- 论文章节：3.4.4、4.4.2
- 答辩一句话："RT-2 一类端到端方案缺少可审计约束，我们坚持 LLM 规划 +
  动作契约 + 安全层，这是软件工程方法转化 LLM 能力的关键。"

---

## 模块 6：实验验证

- 相关论文：[6] SayCan 评估（101 条指令）、扩展工厂机器人论文（仿真+真实
  工厂）、[10] ROS2（系统级验证）
- 核心观点：验证应覆盖任务理解、执行闭环和稳定性，而不只是规划成功率
- 项目对应：规划器对比（12 任务/49 变体）、RAG 对比、RobotStudio 闭环
  执行（11/11）、稳定性测试（断连/压测/长空闲）
- 论文章节：5.2~5.5
- 答辩一句话："实验分三层：语言变体对比证明 LLM 理解优势（82% vs 16%），
  RAG 对比证明知识增强作用，闭环执行和稳定性测试证明工程可靠性。"

## 模块 7：未来方向

- 相关论文：[8] PaLM-E、[9] RT-2、[7] Inner Monologue、具身 AI 综述、
  Foundation Models
- 核心观点：具身智能走向多模态输入、端到端 VLA、执行中实时反馈与再规划
- 项目对应：第 6 章四个展望——视觉语言机器人、Robot Agent 自主化、
  多智能体、工业智能系统
- 论文章节：6.3
- 答辩一句话："PaLM-E 展示了多模态 token 进 LLM 的方向，Inner Monologue
  展示了执行反馈驱动再规划，这两条是我们未来升级的具体路径。"
