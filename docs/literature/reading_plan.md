# 核心论文阅读计划（8 篇）

目标：每篇读懂"解决什么问题、方法是什么、和 AI-Robot-Demo 有什么关系、
答辩被问到怎么回答"。产出：能用自己的话讲 3 分钟。

## 第 1 篇 ReAct [15]

- 阅读目标：理解 Agent 的"推理-行动-观察"循环
- 重点：Thought/Action/Observation 如何交错；为什么比纯思维链少幻觉
- 对应项目：Agent 的"任务理解 → 规划 → 工具调用 → 反馈"
- 答辩回答："我们的 Agent 参考了 ReAct 的闭环思想，但用 JSON 动作契约和
  安全约束层把动作限定在工业可执行范围内"
- 预计用时：2 小时（笔记已写）

## 第 2 篇 SayCan [6]

- 阅读目标：LLM 高层知识与机器人能力怎么结合
- 重点：p(useful) × p(feasible) 选技能；为什么"能力约束语言"
- 对应项目：RobotTool + 安全约束层
- 答辩回答："SayCan 用价值函数做可行性约束，我们用动作白名单和校验规则，
  目的相同——不让 LLM 输出超出机器人能力的话"
- 预计用时：2 小时（笔记已写）

## 第 3 篇 RAG [19]

- 阅读目标：为什么需要外部知识、检索增强流程
- 重点：参数化记忆 vs 非参数化记忆；RAG-Sequence/RAG-Token
- 对应项目：论文 RAG 模块（bge-small-zh + 混合检索）
- 答辩回答："我们的 RAG 沿用了论文'检索+生成'框架，但用轻量嵌入模型和
  自建工业知识库，不做模型微调"
- 预计用时：2 小时（笔记已写）

## 第 4 篇 ROS2 [10]（Macenski）

- 阅读目标：ROS2 的节点/话题/中间件设计动机
- 重点：ROS1 到 ROS2 的架构变化；DDS 通信；实时性、安全性的设计取舍
- 对应项目：GazeboBackend 的 ROS2 话题通信；Robot Interface 的模块化
- 答辩回答："系统底层通信参考 ROS2 的节点化、松耦合设计，Robot Interface
  就是把执行后端像 ROS 节点一样可替换"
- 预计用时：2 小时（PDF 待获取，先用 design.ros2.org 替代）

## 第 5 篇 Software Architecture in Practice [21]（Bass）

- 阅读目标：软件架构的核心概念（质量属性、架构风格、视图）
- 重点：为什么架构决策影响系统演化；分层与模块化
- 对应项目：第 3 章分层架构、接口抽象、后端解耦
- 答辩回答："系统按质量属性（可扩展、可维护、安全）做架构决策，规划层与
  执行层解耦，新增后端只需实现统一接口"
- 预计用时：3 小时（书，读目录和重点章节）

## 第 6 篇 PaLM-E [8]

- 阅读目标：具身智能整体框架，不看模型结构细节
- 重点：多模态 token 进 LLM；跨任务正迁移；机器人在回路
- 对应项目：第 6 章"视觉语言机器人"展望
- 答辩回答："PaLM-E 展示了语言模型直接吃视觉和状态输入的方向，我们当前
  用工具返回文本，未来可升级为多模态输入"
- 预计用时：1.5 小时（笔记已写）

## 第 7 篇 RT-2 [9]

- 阅读目标：VLA 思想，语言到动作
- 重点：动作转成 token 与 VLM 共同微调；涌现推理能力
- 对应项目：了解端到端路线的边界；反衬动作契约方案的价值
- 答辩回答："RT-2 端到端出动作，但工业上需要可审计、可约束，所以我们
  坚持 LLM 规划 + 动作契约 + 安全层"
- 预计用时：1.5 小时（笔记已写）

## 第 8 篇 Inner Monologue [7]

- 阅读目标：执行反馈如何驱动再规划
- 重点：反馈来源（成功检测、场景描述、人类）；闭环价值
- 对应项目：多轮上下文；第 6 章"Robot Agent 自主化"
- 答辩回答："我们目前执行后回传结果更新上下文，Inner Monologue 展示了
  更进一步——执行中实时反馈自动重规划，这是我们的未来方向"
- 预计用时：1.5 小时（笔记已写）

## 阅读方法

1. 每篇先看笔记（reading_notes/）里的"核心思想 + 与 AI-Robot-Demo 关系"；
2. 再翻原文摘要和结论，验证笔记判断；
3. 用"3 分钟讲清楚"标准自查：背景 → 方法 → 结果 → 与我们的关系；
4. 答辩前把 8 篇的"答辩回答"串成一条逻辑线：
   Agent（ReAct）→ 机器人技能（SayCan）→ 知识增强（RAG）→ 系统底层
   （ROS2）→ 软件工程（Bass）→ 未来（PaLM-E / RT-2 / Inner Monologue）。
