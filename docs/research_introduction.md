# 项目研究介绍（联系导师用）

## 1. 项目背景

大语言模型（LLM）展现了强大的自然语言理解与推理能力，如何将 LLM 应用于
机器人任务规划是当前具身智能与人机交互领域的研究热点。传统机器人系统依赖
人工编写的任务逻辑，难以理解自然语言指令；而 LLM 可以直接将口语化任务
翻译为结构化动作序列。

本项目在此基础上进一步引入 **Agent 架构**（可解释规划 + 工具调用）与
**RAG 记忆增强**，构建了一个从"自然语言理解"到"仿真机器人执行"的完整闭环系统。

## 2. 研究问题

1. **任务理解与规划**：如何让 LLM 将模糊的自然语言指令转化为
   可执行、可解释的机器人任务计划？
2. **长期记忆与知识检索**：机器人如何在多轮交互中持久化环境知识，
   并准确召回语义相近的记忆？
3. **感知-规划-执行闭环**：AI 大脑如何与机器人控制系统（ROS2）和
   仿真环境（Gazebo）有效协同？

## 3. 技术路线

```
用户自然语言
  → Streamlit GUI（交互层）
  → AI Agent（可解释 Plan + 工具调用）
  → DeepSeek LLM（任务理解与规划）
  → RAG Memory（语义记忆检索）
  → Tool 调用（memory/robot/vision/environment）
  → ROS2 通信 → Gazebo 仿真 → 状态反馈
```

关键技术：

- LLM 结构化输出（JSON 契约 + 低温采样）
- Agent 工具化架构（BaseTool 统一接口）
- RAG（bge-small-zh 向量嵌入 + 混合检索）
- 机器人中间件（ROS2 话题模型）
- 物理仿真（Gazebo 差速机器人 + 相机）

## 4. 系统创新点

1. **可解释任务规划**：不暴露 LLM 思考链，而是输出结构化的
   `任务分析 / 目标 / 执行步骤 / 当前状态`，兼顾可执行性与科研可观测性
2. **轻量 RAG 记忆**：SQLite + numpy 余弦检索实现语义记忆，
   无需外部向量数据库，适合教学与演示场景
3. **分层双栈架构**：Windows 单机验证 + WSL ROS2/Gazebo 仿真，
   核心模块零修改复用
4. **工具化 Agent 与既有系统解耦**：Agent 通过四类工具驱动
   已有模块，不侵入 V1-V4 代码，双链路共存

## 5. 当前成果

- 完整系统：V1-V5.2 已实现并实测通过，V5.3 RAG 基础模块完成
- 已验证能力：
  - 自然语言任务 → 结构化动作（DeepSeek 真实模式）
  - 长期记忆跨会话持久化
  - 仿真机器人物理导航与视觉感知
  - Agent 可解释规划与工具执行
  - 语义相近问题正确召回记忆（"那个红色东西在哪里" → 红色零件）
- 代码开源在 GitHub（31 个提交，3 个版本 Tag）

## 6. 后续研究方向

1. **RAG 与 Agent 深度集成**：规划时注入语义记忆，评估对任务成功率的提升
2. **Agent 评测体系**：任务成功率、规划质量、响应时间等量化指标
3. **多轮交互**：更完善的对话状态管理与指代消解
4. **真实机器人迁移**：MoveIt / 真实机械臂抓取
5. **具身智能扩展**：视觉语言模型（VLM）替代规则式颜色识别
