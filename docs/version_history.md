# 版本历史

## V1：LLM 任务规划

- **完成内容**：DeepSeek + Python + JSON 任务规划，离线 Mock 模式
- **使用技术**：DeepSeek API（OpenAI 兼容）、Python、prompt 工程、JSON 契约
- **解决的问题**：把自然语言任务转成机器可执行的结构化动作指令
- **后续方向**：为记忆系统提供"任务理解"基础

## V2：Memory 长期记忆

- **完成内容**：SQLite 记忆系统（环境信息/物体信息/用户知识）、上下文注入
- **使用技术**：SQLite、关键词检索、prompt 模板
- **解决的问题**：大模型无状态，机器人记不住环境与历史
- **后续方向**：升级为语义检索（V5.3 RAG）

## V3：ROS2 机器人通信

- **完成内容**：ROS2 节点体系（task_cli / ai_brain / robot_controller）+ 话题通信
- **使用技术**：ROS2 Humble、rclpy、launch
- **解决的问题**：让 AI 大脑成为机器人系统中的一个标准节点
- **后续方向**：接入真实传感器与执行器

## V4：Gazebo 机器人仿真

- **完成内容**：差速机器人 + 相机 + 颜色识别 + 物理导航
- **使用技术**：Gazebo 11、URDF、OpenCV HSV、差速驱动插件
- **解决的问题**：在仿真中验证"视觉感知 + 物理执行"闭环
- **后续方向**：机械臂抓取、YOLO 视觉升级

## V5.1：GUI 系统

- **完成内容**：Streamlit 图形界面（任务对话/工作台/记忆/视觉/机器人状态）
- **使用技术**：Streamlit、rclpy 客户端、语言配置文件
- **解决的问题**：命令行交互门槛高，无法直观展示系统状态
- **后续方向**：实时视频流、多会话管理

## V5.2：Agent 智能规划

- **完成内容**：Agent 层（可解释 Plan + 四工具 + 指代消解 + 会话上下文）
- **使用技术**：DeepSeek、工具化架构、ROS2 话题驱动
- **解决的问题**：单次任务规划升级为可解释、可观测的智能体行为
- **后续方向**：工具并行、多步分解、评测

## V5.3：RAG 语义记忆

- **完成内容**：向量嵌入 + SQLite 向量表 + 混合检索（基础模块）
- **使用技术**：bge-small-zh-v1.5、sentence-transformers、numpy 余弦相似度
- **解决的问题**：关键词匹配无法召回语义相近的表达
- **后续方向**：Agent/GUI 集成、增量更新、向量索引升级
