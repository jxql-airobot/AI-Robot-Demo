# 实验记录体系

## 1. 功能介绍

本文件建立统一的实验记录模板，用于：

- 记录 Agent 系统各项任务的执行表现
- 采集论文/毕设所需的量化指标
- 对比不同版本（V3 直连 / V5.2 Agent / V5.3 RAG）的效果差异

## 2. 技术选择原因

- 实验指标与系统能力一一对应（成功率 → 可靠性；响应时间 → 实时性；
  AI 规划时间 → LLM 开销；RAG 召回 → 记忆有效性）
- 表格化记录便于后续统计分析与论文制图

## 3. 数据流程

```
设计实验任务集 → 逐条执行 → 记录指标 → 汇总统计 → 分析结论
```

### 5.3 评测观察（LLM 稳定性）

同一任务集重复 3 轮采样，总体成功率在 **88.9%~100%** 之间波动：

- 偶发失败 1：DeepSeek 对语义指代任务返回「无法执行」（0 步骤）——LLM 偶发理解失败
- 偶发失败 2：DeepSeek 用 pick+place 两步完成「移动」任务（语义等价），
  早期严格标准（仅接受 move）误判失败 → 已放宽评测标准为「robot_tool + 目标正确」
- 结论：聚合指标稳定（3 轮均 ≥88.9%），单轮存在 LLM 波动，
  论文实验建议每任务 ≥5 轮取均值，并记录失败样本

### 5.4 指标定义

- **成功率**：计划匹配任务期望（工具/动作/目标）且所有已执行步骤 ok
- **响应时间**：Agent.handle 总耗时（含规划 + 执行）
- **AI 规划时间**：planner.plan 耗时（DeepSeek API 调用为主）
- **工具执行时间**：executor 耗时（本地 SimRobot 接近 0s；ROS2 模式含通信）
- **RAG 召回率**：期望记忆是否进入查询 top-3（来源：语义检索/关键词检索）
