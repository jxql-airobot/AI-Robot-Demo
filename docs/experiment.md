# 实验记录体系

## 1. 功能介绍

本文件建立统一的实验记录模板，用于：

- 记录 Agent 系统各项任务的执行表现
- 采集论文/毕设所需的量化指标
- 对比不同版本（V3 直连 / V5.2 Agent / V5.3 RAG）的效果差异

## 2. 技术选择原因

- 实验指标与系统能力一一对应（成功率 → 可靠性；响应时间 → 实时性；
  AI 规划时间 → LLM 开销；RAG 召回 → 记忆有效性）
- 表格化记录便于后续统计分析与论文制图

## 3. 数据流程

```
设计实验任务集 → 逐条执行 → 记录指标 → 汇总统计 → 分析结论
```
