# Gazebo 仿真设计

## 1. 功能介绍

Gazebo 层提供机器人物理仿真环境：

- 差速轮机器人（底盘 + 双轮 + 前后万向轮 + 顶部相机）
- 红/蓝/绿三个彩色零件（纯视觉模型，无碰撞，为抓取预留）
- 相机传感器 → OpenCV 颜色识别闭环
- 物理导航：控制器根据 /odom 发布 /cmd_vel 驱动机器人开往工位

## 2. 技术选择原因

- **URDF**：描述机器人几何、关节、传感器，是 Gazebo 仿真机器人的"身份证"
- **gazebo_ros 插件**：diff_drive（差速驱动 + 里程计）、camera（图像发布），
  与 ROS2 无缝对接
- **纯视觉零件**：去掉碰撞体避免挡住机器人，同时为 V6 机械臂抓取预留
- **万向轮零摩擦**：固定球体无法滚动，设零摩擦模拟滑动支撑

## 3. 数据流程

```
URDF → robot_state_publisher → /robot_description → spawn_entity → Gazebo
Gazebo diff_drive 插件 → /odom + /cmd_vel
Gazebo camera 插件 → /camera/image_raw → vision_node → /ai_robot/vision + SQLite
robot_controller：/odom → 目标工位坐标 → /cmd_vel（转向-直行控制）
```

### 机器人参数

| 参数 | 值 |
| --- | --- |
| 底盘 | 0.5×0.4×0.1 m 箱体 |
| 轮子 | 半径 0.1m，轮距 0.44m |
| 相机 | 320×240 RGB，5fps，安装高度 2m 朝下 |
| 工位 | 上料区 (0,-0.4)、检测区 (0,0.5)、成品区 (0,1.4) |

### 导航控制

```
先转向目标方向（比例控制 + 阻尼，误差 < 0.1 rad）
→ 再直行（速度随距离减小，最低 0.15 m/s）
→ 距离 < 0.25m 判定到达，停止
```

## 4. 当前实现状态

- 机器人物理行驶到工位实测通过（4 秒内到达检测区）
- 相机画面识别出红/蓝/绿零件及左右区域
- 视觉结果写入记忆：`红色零件 -> 右侧区域（视觉识别）`
- 已知限制：零件无碰撞（纯视觉），机器人导航精度依赖里程计漂移

## 5. 未来扩展方向

- V6：真实机械臂 / MoveIt 仿真抓取（零件无碰撞就是为抓取预留的）
- 导航改进：速度/精度调优、到达后掉头
- 视觉升级：YOLO 目标检测替换 HSV 颜色识别
- 相机外观：加支架杆或降低安装高度
