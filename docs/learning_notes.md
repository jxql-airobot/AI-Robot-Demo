# 个人学习总结

> 以本科学生科研成长记录角度撰写。

## 1. 学习了哪些技术

### 1.1 大语言模型调用

- **学了什么**：OpenAI 兼容 API 调用、模型参数（temperature）、JSON 输出模式
- **作用**：让 DeepSeek 从"聊天模型"变成"任务规划器"
- **为什么这样设计**：`response_format=json_object` + 低温（0.1）保证输出
  稳定可解析，JSON 作为人机翻译契约
- **遇到的问题**：模型偶尔返回无法解析的内容 → 设计 error 动作兜底；
  API Key 无效时自动降级离线 Mock

### 1.2 Prompt 设计

- **学了什么**：System Prompt 限定角色、动作集合、输出格式
- **作用**：把自然语言任务约束到可执行的动作空间
- **为什么这样设计**：限定动作类型（move/pick/place/scan/status）+ 示例，
  模型才能稳定输出契约内指令
- **遇到的问题**：无约束时模型自由发挥 → 严格 JSON schema + 示例约束解决

### 1.3 Agent 架构

- **学了什么**：可解释 Plan、工具调用、会话上下文、指代消解
- **作用**：从"单次规划"升级为"理解-计划-执行-反馈"的智能体闭环
- **为什么这样设计**：不暴露 LLM 思考链，输出结构化
  `任务分析/目标/执行步骤/当前状态`，科研演示可观测
- **遇到的问题**：工具与底层耦合 → BaseTool 统一接口 + 依赖注入解耦

### 1.4 RAG（检索增强生成）

- **学了什么**：向量嵌入、余弦相似度、混合检索、向量存储
- **作用**：让关键词匹配升级为语义匹配（"那个红色东西"→"红色零件"）
- **为什么这样设计**：bge-small-zh 中文效果好体积小，SQLite + numpy
  免去外部向量数据库
- **遇到的问题**：torch CPU 国内下载困难 → Windows 侧下载 wheel 再本地安装；
  系统旧版 Pillow/scipy 冲突 → 强制升级解决

### 1.5 ROS2

- **学了什么**：节点、话题、launch、rclpy
- **作用**：AI 大脑成为机器人系统的标准节点
- **为什么这样设计**：发布-订阅模型天然适合"指令下发 + 状态广播"
- **遇到的问题**：节点残留导致端口/重名冲突 → 启动脚本自动清理

### 1.6 Gazebo

- **学了什么**：URDF、SDF、传感器插件、差速驱动、物理导航
- **作用**：在仿真中验证"感知-规划-执行"闭环
- **为什么这样设计**：Gazebo 与 ROS2 集成成熟，仿真成本远低于真机
- **遇到的问题**：相机默认朝 +X → 绕 Y 轴转 90° 朝下；
  两轮前倾 → 加万向轮；零件挡路 → 去掉碰撞体

### 1.7 软件工程

- **学了什么**：Git 规范、版本 Tag、文档体系、测试、跨平台脚本
- **作用**：项目从"能跑"变成"可维护、可展示、可开源"
- **为什么这样设计**：Conventional Commits + 版本 Tag 让时间线可追溯；
  文档体系支撑毕设与软著材料
- **遇到的问题**：Windows/WSL 中文乱码 → Windows Terminal + UTF-8 统一；
  cmd 批处理中文 → PowerShell 启动器 + ASCII 包装

## 2. 每个技术的作用与为什么这样设计

| 技术 | 作用 | 为什么这样设计 |
| --- | --- | --- |
| DeepSeek | 任务理解与规划 | 中文好、JSON 稳定、成本低 |
| Prompt 工程 | 约束模型输出 | 结构化契约保证可执行 |
| Agent | 可解释智能体行为 | 工具化 + Plan 可观测 |
| RAG | 语义记忆召回 | 关键词匹配的升级 |
| ROS2 | 机器人通信标准 | 发布-订阅解耦 |
| Gazebo | 物理仿真验证 | 低成本闭环测试 |
| Streamlit | 可视化交互 | Python 原生、科研演示友好 |
| Git/文档 | 工程化管理 | 可追溯、可展示、可开源 |

## 3. 遇到的问题汇总

- 中文乱码（cmd/终端）→ Windows Terminal + UTF-8
- numpy 2.x 与 cv_bridge 冲突 → 锁定 numpy 1.26.4
- GitHub 直连被重置 → SSH over 443
- torch 国内下载慢 → 镜像探测 + Windows 下载本地安装
- 系统旧版 Pillow/scipy → 强制升级
- WSL 命令引号被破坏 → 一律写脚本文件
- Gazebo 空世界 → 启动前清理残留 gzserver
